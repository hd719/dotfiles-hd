# iStat Menus

`iStat Menus Settings.ismp7` is a manual settings backup.

On 2026-10-31, the saved combined-menu layout and version metadata were
refreshed from the M3 Max MacBook Pro's live iStat Menus 7.50 preferences
(build 2355). Other saved preferences were preserved. This file is not
automatically applied; restore it through iStat Menus' settings import when
explicitly requested.

Before committing a new export, remove every `Device.*` and `License.*`
key-value pair. Device authentication, licenses, and activation state remain
machine-owned and must never enter the repository.
